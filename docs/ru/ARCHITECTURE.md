# Архитектура

GemmaM5-1 FullStack является эксплуатационной конфигурацией вокруг LM Studio, а не новым движком инференса.

1. **Исполнительный слой:** LM Studio, ускорение Metal, загрузка GGUF, KV-cache и локальные API.
2. **Модельный слой:** Gemma 4 26B A4B QAT. Полный набор весов остается адресуемым, хотя MoE-маршрутизация активирует только часть экспертов для каждого токена.
3. **Прикладной слой:** чат, изображения, документы/RAG, OpenAI-совместимые клиенты и native API LM Studio.
4. **Доверенный слой:** проверка tool calls на стороне хоста, allowlist MCP, привязка только к loopback-интерфейсу и явное подтверждение потенциально разрушительных операций.

Начальный контекст 8192 выбран как средство управления памятью. Размер файла весов не равен полной нагрузке на unified memory: дополнительно учитываются macOS, vision encoder, KV-cache, runtime buffers и активные приложения.

Сервер проекта привязывается к `127.0.0.1`. Изменение адреса на `0.0.0.0` или сетевой интерфейс создает иную модель угроз и требует отдельного проектирования: API-токена, правил firewall, политики клиентов и проверки утечки данных.

## Acceptance path (1.1.90)

`examples/fullstack_acceptance.py` отправляет ограниченный проверенный UTF-8 фрагмент и одно изображение на loopback OpenAI-compatible endpoint, затем использует тот же фиксированный read-only tool с host validation. Индексации документов нет; это не RAG engine общего назначения.
