# Протокол аппаратного benchmark

Версия репозитория: 1.1.240

Это единственная поддерживаемая процедура перевода `benchmarks/m5-air-24gb.template.json` из состояния `not_measured` в `measured`. Статическая проверка не заменяет непосредственный запуск на MacBook Air M5 владельца.

## Профиль доказательства

Используйте неизменный набор запросов и запишите его SHA-256. Для каждой рабочей точки выполните не менее трёх повторов. Укажите, был ли первый запуск холодным. Отдельно измерьте скорость prefill и decode, а также time to first token и совокупную скорость генерации.

Обязательны контексты 4K и 8K. Контекст 32K необязателен и остаётся экспериментальным для профиля 24 ГБ. Число одновременных предсказаний равно одному. Зафиксируйте сборку macOS, версию LM Studio, разрешённый `modelKey`, memory pressure до загрузки, после загрузки и на пике, swap до/после и thermal state.

## Последовательность приёмки

1. Выполните `./scripts/verify_repo.sh` и `./scripts/preflight.sh`.
2. Выполните `make hardware-report`; проверьте файл с правами 0600 до хранения или публикации.
3. Зафиксируйте происхождение модели командой `make provenance`.
4. Выполните text, vision, controlled-tool и `make fullstack` acceptance.
5. Запустите неизменный benchmark не менее трёх раз для каждого объявленного контекста.
6. Внесите только непосредственно измеренные значения и выполните `make benchmark-check`.

Неудачный или прерванный запуск отмечается как `rejected` с пояснением, а не превращается в показатель производительности.
