# Support

Repository version: 1.1.240

Use GitHub Issues for reproducible repository defects and documentation errors. Do not paste API tokens, SSH private keys, private document contents, raw local model paths or model weights.

For security-sensitive reports, follow `SECURITY.md` and avoid public disclosure until the maintainer has reviewed the issue. Hardware-performance questions must include the redacted environment fields required by the benchmark protocol; unmeasured estimates should be labelled as such.
