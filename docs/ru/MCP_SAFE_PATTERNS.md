# Безопасные шаблоны MCP

MCP расширяет доверенную границу за пределы модели и LM Studio. Начинайте с минимального полезного разрешения.

## Первый тест

Используйте публичный read-only сервер поиска и ровно один инструмент из allowlist, как в `config/mcp_request.example.json`. Не сохраняйте токены и учетные данные в JSON-файле.

| Класс доступа | По умолчанию | Минимальная проверка |
| --- | --- | --- |
| Публичный read-only поиск | Выключен | Проверить URL сервера, владельца и JSON-схему инструмента |
| Чтение одного каталога проекта | Выключено | Зафиксировать каталог; запретить `..` и выход через symlink |
| Управление браузером | Выключено | Отдельный профиль без сохраненных паролей и allowlist доменов |
| Почта, календарь, облачное хранилище | Выключено | Least privilege и отдельное подтверждение любой записи |
| Shell или запуск процессов | Запрещено этим репозиторием | Нужен отдельный sandboxed-проект и независимый аудит |

Для каждого MCP-запроса задавайте `allowed_tools`. Отсутствие поля может открыть модели весь набор инструментов, который публикует сервер.
## Исполняемый пример

После запуска локального сервера проверьте отслеживаемый шаблон и отправьте его командой:

```bash
MODEL_IDENTIFIER=gemma4-local ./examples/mcp_request.sh
```

Исполняемый запрос по умолчанию разрешает только числовой loopback-адрес. Значение `LM_NATIVE_BASE_URL` вне loopback принимается лишь с явным флагом `--allow-remote-base-url`. Такой выбор означает, что тело запроса и `LM_API_TOKEN`, если он задан, покидают Mac; удалённый endpoint следует рассматривать как отдельную доверенную границу.

```bash
LM_NATIVE_BASE_URL=https://203.0.113.1/api/v1 \
  ./examples/mcp_request.sh --allow-remote-base-url
```

Сценарий находит стандартный шаблон относительно корня репозитория, требует хотя бы одну интеграцию `ephemeral_mcp`, отклоняет пустой список `allowed_tools` и записывает выбранный идентификатор модели только во временный payload. Отслеживаемый JSON-шаблон не изменяется. Другой шаблон можно явно передать первым аргументом.
