# Политика зависимостей

Версия репозитория: 1.1.240

Релизные сценарии используют стандартную библиотеку Python и системные средства macOS. GitHub Actions закреплены полными неизменяемыми commit и отражены в реестре источников. Установка runtime не выполняет скрытое обновление: `scripts/install_lm_studio.sh` устанавливает LM Studio при отсутствии, а для обновления уже установленной версии требует явный ключ `--upgrade`.

Обновление зависимости допустимо только после синхронизации точного источника, документации текущей версии, unit checks, статической матрицы, детерминированного ZIP и повторной проверки чистой распаковки. Сам факт выхода новой версии не включает её автоматически в проверенную границу runtime.
