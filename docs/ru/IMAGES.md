# Иллюстрации

`banner.png` — титульная полоса README. `architecture.png` — функциональная схема. `memory_budget.png` — иллюстративный, а не измеренный бюджет. `installation_flow.png` — последовательность публикации и приемки. `vision_test.png` — контрольное изображение с ожидаемым числом 417.

## Автоматический visual gate (1.1.90)

`docs/assets/assets-manifest.json` фиксирует размеры, назначение и минимальное пустое поле каждого PNG. `make assets-check` останавливает проверку при входе содержимого в это поле.
