# Контракт совместимости среды выполнения

Версия репозитория: 1.1.240

Репозиторий не выводит совместимость только из строки версии приложения. На целевом Mac `scripts/check_lm_studio_version.sh` сначала требует LM Studio 0.4.11 или новее и рекомендует 0.4.20 или новее. Минимум связан с обновлённой chat template Gemma 4; рекомендация соответствует стабильной ветке, проверенной 24 июля 2026 года. Затем `scripts/verify_lms_cli_contract.sh` проверяет фактически установленный интерфейс команд.

Обязательный публичный контракт CLI:

- `lms get`: `--gguf`, `--yes` и текущий `--select` либо обнаруженный прежний флаг выбора;
- `lms load`: `--context-length`, `--gpu`, `--parallel`, `--identifier`, `--ttl`, `--estimate-only`, `--yes`;
- `lms ls`: `--json`;
- `lms ps`: `--json`;
- `lms unload`: точный позиционный identifier;
- `lms server start`: `--bind`, `--port`;
- `lms server status`: `--json`.

## Контракт точной идентичности

24 июля 2026 года поведение независимо сопоставлено с `lmstudio-ai/lms` ревизии `71bd99ccf882a0410cfd574ee220a99083608930`.

Текущая реализация `lms load --exact` трактует позиционный аргумент как `ModelInfo.path`, а не как `modelKey`. После поиска точного path она загружает соответствующий `model.modelKey`. Поэтому репозиторий извлекает из `lms ls --json` одну неделимую локальную пару:

1. `ModelInfo.path` — передаётся в `lms load --exact --local` и estimator;
2. `modelKey` — независимо проверяется до и после загрузки.

Resolver отклоняет не-Q4_0, удалённые записи LM Link, неполные записи и более одной точной пары path/modelKey. Loader до изменения состояния блокирует коллизии identifier/path/modelKey, допускает идемпотентный no-op только для единственного полностью совпадающего экземпляра и откатывает частичную загрузку по точному identifier.

Скрытые параметры `--exact` и `--local` фактически запускаются в управляемых командах estimate/load. Если установленный CLI перестанет их принимать, операция завершится отказом, а не выбором другой или удалённой модели.

## Контракт целевого оборудования

Preflight требует:

- `MacBook Air`;
- token чипа Apple M5;
- идентификатор `Mac17,3` либо `Mac17,4`;
- arm64;
- не менее 24 ГиБ заявленной объединённой памяти;
- macOS 26.0 или новее.

Эти проверки подтверждают принадлежность к целевому профилю, но не измеренную производительность. После каждого обновления LM Studio/runtime аппаратная приёмка обязательна.

## Граница текущего релиза (2026-07-24)

Защищённый профиль требует LM Studio не ниже 0.4.11, поскольку эта версия содержит обновлённую поддержку шаблона чата Gemma 4, используемую комплектом. Для данного релиза рекомендована проверенная версия приложения 0.4.20. Общая страница системных требований LM Studio сейчас перечисляет M1/M2/M3/M4, но не M5; репозиторий не превращает это отставание документации в недоказанное утверждение. Идентичность M5 и пределы памяти подтверждаются страницами Apple, а фактическая работа LM Studio остаётся предметом приёмки владельца.
