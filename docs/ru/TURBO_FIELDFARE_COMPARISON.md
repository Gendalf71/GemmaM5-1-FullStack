# Структурное сравнение с TurboFieldfare

TurboFieldfare используется только как ориентир профессионального оформления публичного инженерного репозитория: центрированная визуальная идентичность, короткое техническое обещание, badges, быстрый старт, таблица рабочего профиля, архитектурные схемы, эксплуатационные команды, честные границы применимости и отдельные доказательные документы.

Назначение проектов принципиально различается:

| Область | TurboFieldfare | GemmaM5-1 FullStack |
| --- | --- | --- |
| Исполняющая система | Собственный inference runtime на Swift и Metal | LM Studio с защищённой оркестрацией |
| Работа с памятью | Потоковая подгрузка routed experts с SSD | Выбранный QAT GGUF-пакет, загружаемый runtime LM Studio |
| Роль репозитория | Реализация runtime и приложения | Установка, проверка, безопасность, приёмка и публикация |
| Интерфейсы | Собственные Mac-приложение и CLI | LM Studio, localhost API, ограниченные tools и MCP |
| Доказательства | Измерения производительности исходного runtime | Аппаратные утверждения запрещены до приёмки на целевом M5 |
| Граница ответственности | Код контролирует inference engine | Код контролирует профиль и внешние вызовы, но не внутренности LM Studio |

Код, логотип, скриншоты и формулировки TurboFieldfare не копировались. Сходство ограничено иерархией документации и принципом evidence-first. Поэтому GemmaM5-1 FullStack не следует описывать как форк, порт или альтернативную реализацию TurboFieldfare.
Сравнение повторно выполнено по публичному репозиторию 24 июля 2026 года. Сохранён только паттерн подачи: идентичность до деталей, короткий исполняемый маршрут, таблица рабочего профиля, наглядная архитектура, разделение измеренного и неизмеренного, границы применимости, технические приложения и явная граница лицензий/модели. В GemmaM5-1 FullStack эти принципы применены к assurance и оркестрации, а не к имитации чужих метрик или реализации.


Release 1.1.240 adds machine-checked visual margins, owner-evidence states and an explicit backend boundary; these are presentation/assurance improvements, not copied runtime claims.
