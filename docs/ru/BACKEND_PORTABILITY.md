# Граница переносимости backend

Версия репозитория: 1.1.240

Проверенная реализация этого выпуска поддерживает **только LM Studio**. Сценарии разрешения точной модели, загрузки, сервера, аутентификации и постусловий используют текущий CLI `lms` и не становятся переносимыми простой заменой названия команды.

MLX, llama.cpp и Ollama могут служить объектами сравнения или миграции, но **не прошли аудит как backend этого репозитория**. Будущий адаптер обязан отдельно доказать точную идентичность модели, квантование, контекст, GPU/offload, параллелизм, loopback/authentication, rollback состояния, границу tools и benchmark.

Переносимы модель доказательств, безопасная политика локального API, строгая проверка фиксированного инструмента, схема benchmark, входы document/vision acceptance и публикационный workflow. Runtime-зависимые команды изолированы в `scripts/`.
