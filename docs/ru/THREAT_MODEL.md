# Модель угроз

Версия репозитория: 1.1.240

## Защищаемые активы

SSH-ключи GitHub, API-токены, локальные пути, частные документы, происхождение модели, целостность выбранной модели и локальная граница исполнения.

## Основные угрозы

1. Выбор похожей записи каталога либо неверной квантизации.
2. Prompt injection пытается превратить вывод модели в shell-команду или опасное MCP-действие.
3. API привязывается не только к loopback либо работает без аутентификации.
4. Доступный для записи, повреждённый или symlink-конфиг меняет политику.
5. Архив содержит незаявленные файлы, веса, секреты или traversal-пути.
6. Изменяемый либо устаревший pin GitHub Actions делает зелёный CI вводящим в заблуждение.
7. Скриншоты и отчёты владельца раскрывают пути, токены или содержимое документов.

## Меры

Точная идентичность модели, fail-closed грамматика конфигурации, фиксированный read-only tool, MCP allowlists, loopback/auth gates, неизменяемые commit GitHub Actions, staging только по manifest, детерминированная проверка ZIP, owner-only артефакты режима 0600 и обязательная редактура перед публикацией.

## Остаточный риск

LM Studio, runtime и веса остаются внешними компонентами. Статические тесты не доказывают будущую доступность источников, отсутствие внешних уязвимостей или физическую производительность M5. После каждого обновления runtime, модели либо macOS требуется новая приёмка владельцем.
