# Русская документация

**Текущий релиз:** `1.1.240`. Репозиторий является комплектом установки, проверки и публикации, а не новым inference engine и не архивом весов модели.

## Безопасный первый запуск

Из корня репозитория:

```bash
./scripts/verify_repo.sh
./scripts/preflight.sh
```

Эти команды не скачивают модель, не запускают сервер и не подключаются к GitHub. После них переходите к установке модели, estimator и аппаратной приёмке строго по документам ниже.
