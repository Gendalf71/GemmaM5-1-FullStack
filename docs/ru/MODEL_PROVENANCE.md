# Происхождение модели и граница воспроизводимости

## Что фиксирует репозиторий

Релиз фиксирует и проверяет файлы репозитория, поддерживаемый идентификатор каталога, обязательную квантизацию `Q4_0`, локальный идентификатор модели, начальный контекст, привязку API к localhost и процедуру приёмки. Релизные ZIP-файлы собираются детерминированно и снабжаются SHA-256.

## Что репозиторий не может зафиксировать самостоятельно

Веса модели находятся вне репозитория. Запись каталога LM Studio `google/gemma-4-26b-a4b-qat` и исходные файлы Hugging Face являются версионируемыми внешними ресурсами. Вышестоящий владелец может опубликовать исправление без изменения этого репозитория. Поэтому корректно говорить о **повторяемой конфигурации**, а не о неизменности сторонних байтов.

Поддерживаемый профиль остаётся строгим:

```text
Каталог: google/gemma-4-26b-a4b-qat
Формат: GGUF
Квантизация: Q4_0
Локальный идентификатор: gemma4-local
```

## Фиксация установленного варианта

После загрузки модели и определения точного ключа на целевом Mac выполните:

```bash
make provenance
cat artifacts/model-provenance.json
```

Команда:

1. требует macOS и работоспособный CLI `lms`;
2. повторно проверяет фиксированный каталог и `Q4_0`;
3. определяет точный установленный ключ модели;
4. читает `lms ls --json`;
5. сохраняет только разрешённый набор метаданных;
6. исключает локальные пути и учётные данные;
7. записывает отчёт с правами владельца в исключённый из Git каталог `artifacts/`.

Отчёт подтверждает выбранный вариант каталога и локальный runtime-инвентарь. Он не является криптографической контрольной суммой всех внешних файлов весов, поскольку текущий инвентарь LM Studio не предоставляет управляемый этим репозиторием digest для такой гарантии.

## Доказательная база для публикации benchmark

Запись benchmark должна содержать версию репозитория, provenance-отчёт, версии macOS, LM Studio и runtime, ключ модели, длину контекста, тепловое состояние и memory pressure. Историческую запись нельзя исправлять так, будто она относится к другой загрузке модели: для новой загрузки создаётся новый датированный результат.
